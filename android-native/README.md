# RabbitFarm Android 2.0

Офлайн Android-приложение на системном WebView, Android 9+ с обновлённым Android System WebView. Все HTML/CSS/JS включены в APK. Внешние страницы не загружаются, JavaScript-мост доступен только встроенным файлам. Разрешения: уведомления и получение события перезагрузки.

## Возможности

Восемь связанных показателей, взрослые самцы/самки, фото, возраст, клетки, вязки длительностью 1–5 дней, окролы, молодняк, остатки, история выбытия, отсадка через 45 календарных дней, фактическая дата отсадки, отмена последнего действия, JSON-копии, очистка и восстановление. Поиск и фильтры не добавлялись.

База и снимок отмены атомарно сохраняются во внутренних файлах Android. Фотографии выбираются через системный диалог, копии сохраняются через системный выбор места. В Android уведомления об отсадке планируются на утро соответствующей даты без запроса точных будильников; фактическое время зависит от Android, разрешений и энергосбережжения. Состояние расписания восстанавливается после перезагрузки. Закрытый/отсаженный/выбывший помёт исключается из расписания.

## Две сборки и старая база

- Preview/debug: `com.rabbit.farm.preview`, имя «Ушастый учёт · тест». Устанавливается рядом со старым приложением. Не читает чужую закрытую базу `com.rabbit.farm` и не переносит её автоматически.
- Release/update: `com.rabbit.farm`, versionCode 3. Для установки поверх старого приложения требуется его исходный ключ подписи. Сохранённый старый app-debug.apk имеет SHA-256 сертификата `4ab6834f09cfed26029f6a53dd788834aa1eba01c73445c8fb71000363f7c3f0`.

При совместимом обновлении первого приложения новый интерфейс читает старые rabbit_prefs, сохраняет старые preferences без изменений, переносит доступные фото и сверяет базу. Успешная миграция отмечается отдельно, повторный запуск не создаёт дубликатов. Если база новой версии уже непустая, автоматическая замена не выполняется. Старые связи, отсутствующие в исходном формате, не выдумываются; архив сохраняется в резервных копиях.

Ключ старого приложения в исходники не включён. Пароль к переданному ushastyi-uchet-key.jks не сообщался; совместимая release-подпись не подтверждена. Старое приложение нельзя удалять ради установки APK: сначала требуется проверенная копия.

## Android Studio

Открыть эту папку как отдельный проект. Gradle wrapper 8.9 включён, Android Gradle Plugin 8.7.3, compile/target SDK 35, min SDK 28, Java 8, JDK 17+ для Gradle. Debug получает суффикс `.preview`; Release подписывается исходным ключом через Generate Signed APK.

Поставляемый Preview подписан отдельным тестовым ключом `RabbitFarm-preview-signing.p12`, alias `androiddebugkey`, стандартный тестовый пароль `android`. Сам ключ хранится отдельно от публичного репозитория. Чтобы обновлять именно эту тестовую установку, нужно использовать тот же тестовый ключ; стандартный ключ Android Studio может отличаться.

## Сборка без Gradle

`build-apk.py` поддерживает сборку через официальные Android build-tools 35.0.0, android.jar API 35 и Eclipse ECJ 3.38.0. Пароль подписи передаётся через переменную окружения, а не сохраняется в проекте.

Пример: `python3 build-apk.py --tools /path/to/build-tools --android-jar /path/to/android.jar --ecj /path/to/ecj.jar --out /path/to/output --preview --keystore /path/to/preview.p12`

Перед запуском установить ANDROID_STORE_PASSWORD. Без --keystore получается неподписанный файл; он не предназначен для установки.

## Проверки

Java-код компилируется, D8 создаёт DEX, aapt2 собирает ресурсы и manifest, zipalign выравнивает архив, apksigner проверяет подпись и min SDK. Все `tests/*.cjs` запускаются через Node.js: баланс, миграция тестового старого формата, отмена, клетки, копии, переходы, интеграция хранилища и расписание уведомлений.

На реальном Android-устройстве запуск, системные диалоги, уведомления и перенос реальной пользовательской базы ещё не проверялись.
