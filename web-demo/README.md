# RabbitFarm — мобильная веб-версия

Связанный учёт: взрослые → вязка → окрол → молодняк → отсадка → взросление либо выбытие. Главная содержит восемь показателей. Баланс: за всё время = сейчас + продано + на мясо + падёж.

Статические файлы находятся в web-demo/. Запуск — через HTTP-сервер. Автоматические проверки: `node tests/accounting.test.cjs`, `node tests/backup.test.cjs`, `node tests/navigation.test.cjs`, `node tests/reset.test.cjs`, `node tests/review.test.cjs`, `node tests/cage-undo.test.cjs`.

## Карточка взрослого

Фото, точный или приблизительный возраст и необязательный номер клетки (`cage`, строка до 30 символов). Клетка видна в списке, редактируется в карточке и включается в резервные копии. При переводе молодняка во взрослые можно назначить клетку переводимой группе. Несколько животных могут находиться в одной клетке. Поиск и фильтры не добавлялись.

## Отмена

Один последний сохранённый шаг: добавление, изменение карточки, вязка, окрол, выбытие, отсадка, взросление, импорт или очистка. Перед отменой показывается подтверждение. Полный снимок до изменения атомарно сохраняется вместе с текущей базой и переживает перезагрузку. Переходы между вкладками не расходуют отмену. Цепочка отмен и повтор действия не предусмотрены. Снимок отмены не включается в экспорт: сама база, фото и номера клеток входят в резервную копию.

## Данные и перенос

Записи и фотографии хранятся в браузере, ключ rabbitfarm-demo-v1. Новая база пуста. Раздел «Данные» позволяет сохранить JSON, проверить импорт до замены базы, очистить записи с подтверждением ОЧИСТИТЬ и восстановить одну предыдущую локальную копию. Исходный архив старого Android-формата сохраняется при миграции. Неизвестные связи не выдумываются.

Ожидаемый окрол через 31 день — ориентир; отсадка через 45 дней. Напоминания отображаются внутри страницы. Синхронизации с Android и фоновых уведомлений нет. Подготовка промежуточного Android-обновления с экспортом описана в ANDROID_TRANSFER.md; подписанный APK с новым интерфейсом ещё не собран.
