# RabbitFarm mobile demo

Компактное веб-демо: взрослые самцы и самки → вязка → окрол → молодняк → отсадка → перевод во взрослые либо выбытие.

Главная показывает восемь показателей в два столбца: сейчас в хозяйстве, взрослые (самцы/самки), молодняк, продано, на мясо, падёж, вязки, всего за всё время. Подробности открываются нажатием.

## Баланс поголовья

- Сейчас = оставшиеся взрослые + оставшийся молодняк (включая отсаженных).
- За всё время = внешние поступления взрослых + все живорождённые в зарегистрированных окролах.
- За всё время = сейчас + продано + на мясо + падёж.
- Отсадка не меняет категорию молодняка. Перевод во взрослые уменьшает молодняк и увеличивает взрослых без изменения общего количества.
- Выбытие невозможно в количестве больше текущего остатка. Выбывшие животные остаются в истории; родители и помёты сохраняют связь.
- Вязки — отдельное количество событий за всё время, рядом показаны ожидаемые окролы.

## Запуск и проверка

Статические файлы находятся в web-demo/. Откройте через любой локальный HTTP-сервер. Проверка расчётов: `node tests/accounting.test.cjs`.

Демо содержит примерные данные, хранит записи в localStorage браузера под прежним ключом rabbitfarm-demo-v1 и экспортирует JSON. Существующие записи вязок и окролов сохраняются при обновлении; взрослые родители из прежнего демо добавляются при переходе на новый учёт. Это не импорт реальной базы Android.

Ожидаемый окрол: 31 день (ориентир); отсадка: 45 дней. Напоминания отображаются при открытии. Синхронизации с Android и фоновых уведомлений нет.
