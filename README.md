# RabbitFarm

Восстановленные исходники Android-приложения RabbitFarm (`com.rabbit.farm`).

Исходники извлечены из пользовательского архива `app.7z`.

**Важно:** для полноценной сборки потребуется оригинальная папка `gradle/`, в частности `gradle/libs.versions.toml` и `gradle/wrapper/gradle-wrapper.jar`. Они не были доступны в переданных файлах.

Не публикуйте ключ подписи `.jks`, `local.properties` и пароли.

Найденная готовая debug APK предоставляется отдельно, в этот архив не включена.


APK сборка: GitHub Actions → Android APK → артефакт RabbitFarm-Android-APK.


## RabbitFarm 2.0 — новый дизайн

Отдельное Android-приложение com.rabbit.farm.modern. Старая версия остаётся установленной, её данные не удаляются. Новая версия содержит локальный веб-интерфейс из app/src/main/assets/rabbitfarm.html, учёт кроликов, клеток, вязок, окролов, отсадки и резервные копии JSON. Данные старой версии автоматически не доступны отдельному пакету Android; при наличии экспорта их можно перенести через JSON.
